# نوا موبایل — فروشگاه گوشی هوشمند با دستیار هوش مصنوعی

نسخه‌ی کامل‌شده‌ی پروژه: یک فروشگاه اینترنتی گوشی موبایل با طراحی اختصاصی،
ریسپانسیو کامل، و یک **ویجت چت شناور** که:

- همیشه گوشه‌ی پایین-راست صفحه شناور می‌مونه (حتی موقع اسکرول)
- با کلیک، صفحه‌ی گفتگو باز می‌شه و ادامه‌ی مکالمه‌ی قبلی رو نشون می‌ده
- به **کل کاتالوگ محصولات سایت** (مشخصات، قیمت، گارانتی، ارسال) دسترسی داره و
  می‌تونه دربارشون تحلیل و پیشنهاد بده
- امکان **ارسال عکس** داره (مثلاً عکس گوشی فعلی کاربر) و مدل تصویر رو تحلیل می‌کنه
- تاریخچه‌ی مکالمه رو در مرورگر کاربر (localStorage) نگه می‌داره

> از **Groq API** استفاده می‌شه: رایگان (بدون کارت بانکی)، بسیار سریع، فرمت
> درخواست‌هایش دقیقاً مثل OpenAI است.

## ساختار پروژه

```
nova-mobile/
├── server.js          ← بک‌اند (Node.js/Express): سرو سایت + API چت + API محصولات
├── products.json       ← کاتالوگ محصولات (منبع مشترک فرانت‌اند و دستیار هوشمند)
├── package.json
├── .env.example         ← نمونه فایل تنظیمات (API Key)
└── public/
    ├── index.html       ← صفحه‌ی کامل سایت + مارک‌آپ ویجت چت
    ├── style.css         ← طراحی اختصاصی (حالت تیره، انیمیشن، ریسپانسیو)
    └── script.js         ← رندر محصولات، فیلترها، منطق ویجت چت
```

### چرا کاتالوگ در یک فایل مشترک (`products.json`) است؟

هم صفحه‌ی سایت (`/api/products`) و هم دستیار هوشمند (`/api/chat`) از همین
فایل می‌خونن؛ یعنی اگه قیمت یا مشخصات گوشی‌ای رو عوض کنی، هم روی سایت و هم
در جواب‌های دستیار بلافاصله به‌روز می‌شه.

---

## گام ۱: نصب Node.js و پکیج‌ها

```bash
node -v   # باید 18 یا بالاتر باشه
npm install
```

## گام ۲: تنظیم API Key

```bash
cp .env.example .env
```

مقدار `GROQ_API_KEY` را در فایل `.env` با کلید واقعی خودتان از
https://console.groq.com/keys جایگزین کنید.

> ⚠️ **نکته‌ی امنیتی مهم:** در فایل‌هایی که برام فرستادی، یک کلید واقعی Groq
> داخل `.env` وجود داشت. چون این کلید جایی دیده شده (حتی در یک گفتگو با هوش
> مصنوعی)، بهتره از کنسول Groq **همین الان اون کلید رو حذف/rotate کنید** و
> یک کلید جدید بسازید؛ فایل `.env` رو هم هرگز به گیت‌هاب یا جای عمومی آپلود
> نکنید.

## گام ۳: اجرا

```bash
npm start
```

آدرس `http://localhost:3000` را در مرورگر باز کنید.

## قابلیت‌های دستیار هوشمند

| قابلیت | توضیح |
|---|---|
| آگاهی از محتوای سایت | کل کاتالوگ محصولات، قیمت‌ها، گارانتی و شرایط ارسال در system prompt به مدل داده می‌شه |
| پرسش مستقیم از هر کارت محصول | دکمه‌ی «پرسش از دستیار» روی هر کارت، چت رو با یک سوال آماده درباره‌ی همون گوشی باز می‌کنه |
| ارسال عکس | با آیکون گیره، کاربر می‌تونه عکس بفرسته (حداکثر ۸ مگابایت)؛ سرور به‌صورت خودکار مدل رو به مدل چندوجهی (تصویر+متن) سوییچ می‌کنه |
| حافظه‌ی مکالمه | تاریخچه در `localStorage` مرورگر ذخیره می‌شه؛ دکمه‌ی «پاک کردن» کل مکالمه رو ریست می‌کنه |
| ارسال با Enter | Enter می‌فرسته، Shift+Enter خط جدید می‌سازه |

### مدل‌های استفاده‌شده (Groq)

- **متن معمولی:** `llama-3.3-70b-versatile`
- **وقتی عکس پیوست بشه:** `qwen/qwen3.6-27b` (تنها مدل چندوجهی فعال Groq در
  زمان نوشتن این پروژه — طبق مستندات به‌روز
  https://console.groq.com/docs/vision؛ اگر بعداً مدل چندوجهی جدیدی اومد،
  ثابت `VISION_MODEL` در `server.js` رو عوض کن)

> نکته: مدل‌های قدیمی‌تر مثل Llama 4 Scout/Maverick توسط Groq **منسوخ (deprecated)**
> شدن؛ اگه جایی نمونه‌کدی با اون اسم‌ها دیدی، دیگه کار نمی‌کنن.

## بالا آوردن سریع سایت روی اینترنت

همون سه گزینه‌ی قبلی (Render.com، Replit، Railway.app) کار می‌کنن — کافیه
`GROQ_API_KEY` رو در بخش Environment Variables/Secrets همون سرویس بذاری، نه
داخل فایل `.env`.

## نکات امنیتی

- هرگز `.env` را در گیت‌هاب یا هرجای عمومی قرار ندید.
- برای جلوگیری از سوءاستفاده، محدودیت تعداد درخواست بگذارید (مثلاً با پکیج
  `express-rate-limit`) چون تیر رایگان Groq هم سقف تعداد درخواست در دقیقه/روز داره.
- عکس‌های ارسالی کاربر مستقیم به Groq فرستاده می‌شن و روی سرور شما ذخیره
  نمی‌شن؛ اگه نیاز به ذخیره‌سازی داری، حتماً رضایت کاربر و قوانین حریم
  خصوصی رو در نظر بگیر.
